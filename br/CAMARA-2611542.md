# Aperfeiçoa o regime de competência dos Juizados Especiais Cíveis para explicitar a incompatibilidade do rito sumaríssimo com causas que demandem produção probatória complexa, especialmente prova pericial.

**Ementa:** Aperfeiçoa o regime de competência dos Juizados Especiais Cíveis para explicitar a incompatibilidade do rito sumaríssimo com causas que demandem produção probatória complexa, especialmente prova pericial.
