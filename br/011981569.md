# Decreto (municipal) no 674, de 03 de março de 2016

**Ementa:** Atualiza os valores das tabelas de remuneração dos Cargos Efetivos de Oficial Administrativo, constantes nas Leis Municipais 1.054/2005, aumentando os valores do vencimento básico com base autorizado pela Lei Municipal n° 1678/2016.
