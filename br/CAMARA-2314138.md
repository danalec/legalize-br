# Altera o Decreto-Lei nº 2.848, de 7 de dezembro de 1940 – Código Penal, para aumentar as penas dos crimes de furto e roubo quando houver elementos probatórios que indiquem conduta criminal habitual, reiterada ou profissional do agente, e para criar causa de aumento de pena para os crimes de extorsão

**Ementa:** Altera o Decreto-Lei nº 2.848, de 7 de dezembro de 1940 – Código Penal, para aumentar as penas dos crimes de furto e roubo quando houver elementos probatórios que indiquem conduta criminal habitual, reiterada ou profissional do agente, e para criar causa de aumento de pena para os crimes de extorsão, extorsão mediante sequestro e estelionato.
