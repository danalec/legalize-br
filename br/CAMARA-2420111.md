# Altera o Código Civil e o Código Penal Brasileiro, bem como a Lei de Abuso de Autoridade, para impedir que as partes, incluindo os advogados, sejam proibidas de gravar audiência em que estejam participando, bem como institui como modalidade criminosa para a autoridade que tentar frustrar tal direito

**Ementa:** Altera o Código Civil e o Código Penal Brasileiro, bem como a Lei de Abuso de Autoridade, para impedir que as partes, incluindo os advogados, sejam proibidas de gravar audiência em que estejam participando, bem como institui como modalidade criminosa para a autoridade que tentar frustrar tal direito.
