# Altera a Lei Complementar n.º 64, de 18 de maio de 1990, para tornar inelegíveis os que burlarem diretrizes de plano de vacinação para obterem para si ou para terceiros acesso indevido à imunização.

**Ementa:** Altera a Lei Complementar n.º 64, de 18 de maio de 1990, para tornar inelegíveis os que burlarem diretrizes de plano de vacinação para obterem para si ou para terceiros acesso indevido à imunização.
