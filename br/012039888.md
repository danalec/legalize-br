# Decreto (municipal) no 1.717, de 28 de dezembro de 2017

**Ementa:** Estabelece os valores do metro linear de testada dos terrenos e o valor do metro quadrado para apuração do valor venal dos imóveis sujeitos ao imposto Predial e Territorial Urbano, que servirá como base de calculo para lançamento do referido tributo para o exercício de 2018.
