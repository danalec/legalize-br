# Institui o Programa de Reconstrução Dentária para Mulheres Vítimas de Violência Doméstica, no âmbito do Sistema Único de Saúde (SUS), visando garantir o atendimento odontológico especializado para a reconstrução dentária de mulheres que tenham sofrido agressões que comprometam a saúde bucal.

**Ementa:** Institui o Programa de Reconstrução Dentária para Mulheres Vítimas de Violência Doméstica, no âmbito do Sistema Único de Saúde (SUS), visando garantir o atendimento odontológico especializado para a reconstrução dentária de mulheres que tenham sofrido agressões que comprometam a saúde bucal.
