# Decreto (municipal) no 1.632, de 31 de dezembro de 2015

**Ementa:** Estabelece os valores do metro linear de testada dos terrenos e o valor do metro quadrado para apuração do valor venal dos imóveis sujeitos ao imposto Predial e Territorial Urbano, que servirá como base de calculo para lançamento do referido tributo para o exercício de 2016.
